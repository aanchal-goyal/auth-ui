# 🔐 Authentication UI

A modern **Login / Signup user interface** built using **HTML, CSS, and JavaScript**.  
This project demonstrates frontend development skills such as form validation, UI interactions, animations, and responsive design.

---

## 🌐 Live Demo

https://aanchal-goyal.github.io/auth-ui/

---

## ✨ Features

### 🔑 Authentication Interface
- Login form
- Signup form
- Toggle between login and signup

### 🧠 Form Validation
- Required field validation
- Password length validation
- Error messages for invalid inputs

### 👁 Password Visibility Toggle
- Show / hide password feature

### ☑ Remember Me
- Saves user email using **localStorage**

### 🔔 Toast Notifications
- Displays success and error messages

### 🎨 UI / UX
- Smooth animations
- Modern design
- Responsive layout

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
